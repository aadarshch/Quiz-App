# Quiz App

Upload a PDF and get an auto-generated multiple-choice quiz from its content.

## Planned stack

- **Flask + SQLite** — web app and quiz history
- **pypdf** — PDF text extraction (local, no API)
- **Local question generation** — cloze-deletion MCQs built from key terms in the document (no AI/LLM required)

Project scaffolding in progress.
